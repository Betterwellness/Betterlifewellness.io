Automatic local saving
  1. Start server.py using python server.py in this folder.
  2. Add, edit, or delete a product here. It will save to products.json automatically.
  3. Refresh the homepage to see the changes.
  4. Use Download products.json when you want an extra backup.
Local-only: Automatic saving works only while you start server.py on this computer. The server listens on this computer only; it does not publish changes to an online website. Keep a backup of products.json.
